A flexible booking system for managing hall and function room rentals with approval workflow, recurring bookings, and email notifications.

== Description ==

Hall hire and function room booking system is a comprehensive WordPress plugin for managing venue bookings. Perfect for community halls, function rooms, meeting spaces, and event venues.

**Key Features:**

* Public booking form (no login required)
* Admin approval workflow
* Email notifications
* Recurring bookings support
* Multiple areas/rooms per hall
* Configurable operating hours
* Beautiful, modern interface
* Internal time blocking
* Responsive design

**Perfect For:**

* Community halls
* Function rooms
* Meeting spaces
* Event venues
* Co-working spaces
* Conference centers

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/hall-hire-and-function-room-booking-system`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to Hall Bookings → Settings to configure
4. Create at least one bookable area
5. Set your operating hours
6. Add `[hbs_booking_form]` shortcode to a page

== Frequently Asked Questions ==

= Does this work with any theme? =

Yes! The plugin is theme-independent and works with any WordPress theme.

= Can I have multiple booking areas? =

Yes, you can create multiple areas within your hall.

= Do users need to log in to book? =

No, the public booking form works without requiring user registration.

= Can I block time for internal use? =

Yes, you can create internal blocks that prevent public bookings.
